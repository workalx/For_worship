# For Worship

Програма для гітариста групи прославлення на Android-планшеті: пісні з акордами на один екран,
служіння зі свайпом між піснями, тюнер і метроном. Пісні можна знайти в інтернеті або на SongSelect,
фото аркуша розпізнає Google Gemini.

## Встановлення на планшет

1. Відкрийте в Chrome на планшеті адресу програми (GitHub Pages).
2. Натисніть **⋮ → Встановити застосунок** (або «Додати на головний екран»).
3. Запускайте з іконки: програма відкриється на весь екран і працюватиме без інтернету
   (пошук і розпізнавання фото потребують мережі).

## Ключ Gemini (безкоштовно)

1. Відкрийте [aistudio.google.com](https://aistudio.google.com) і увійдіть з Google-акаунтом.
2. **Get API key → Create API key**, скопіюйте ключ.
3. У програмі: **Пісні → Налаштування (шестерня) → Ключ Gemini**, вставте, натисніть **Зберегти** і **Перевірити ключ**.

Фото аркуша розбирає `gemini-3.6-flash`. Модель можна змінити в налаштуваннях.

## Пошук пісень

Введіть назву пісні в рядок пошуку:

- **Шукати в інтернеті** відкриває в браузері пошук «назва chords»
  (Brave Search, Google або DuckDuckGo: вибір у **Налаштування → Пошук в інтернеті**).
  Знайдіть пісню, виділіть і скопіюйте текст з акордами, поверніться в програму й натисніть **Вставити з буфера**.
  Швидше: виділіть текст у браузері → **Поділитися → For Worship** (у встановленій програмі на Android).
- **Шукати на SongSelect** відкриває пошук на SongSelect. Зі сторінки акордів пісню додає в програму
  кнопка **Додати в For Worship** з розширення Chrome: як його встановити — [extension/README.md](extension/README.md).

Фото без ключа Gemini не розпізнаються.

## Імпорт власних пісень

**Пісні → Імпорт файлів**: можна вибрати кілька файлів `.cho`, `.chordpro` або `.txt` одразу
(ChordPro або «акорди над рядком», UTF-8 чи Windows-1251). Пісні зберігаються лише на цьому пристрої;
однакові пісні вдруге не додаються, а пропущені файли показуються з причиною.

## Резервна копія

**Пісні → Налаштування → Зберегти копію бази** зберігає всі пісні й служіння в один файл.
**Відновити з копії** повертає їх (наприклад, на новому планшеті).

## Розробка

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # автоматичні тести
npm run build   # збірка в dist/
```

Іконки генеруються скриптом `python scripts/make-icons.py public/icons`.
Публікація: кожен push у гілку `main` збирає й викладає програму на GitHub Pages
(Settings → Pages → Source: **GitHub Actions**).
