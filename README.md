# For Worship

Програма для гітариста групи прославлення на Android-планшеті: пісні з акордами на один екран,
служіння зі свайпом між піснями, тюнер і метроном. Пошук пісень і розпізнавання фото через Google Gemini.

## Встановлення на планшет

1. Відкрийте в Chrome на планшеті адресу програми (GitHub Pages).
2. Натисніть **⋮ → Встановити застосунок** (або «Додати на головний екран»).
3. Запускайте з іконки: програма відкриється на весь екран і працюватиме без інтернету
   (пошук і фото потребують мережі).

## Ключ Gemini (безкоштовно)

1. Відкрийте [aistudio.google.com](https://aistudio.google.com) і увійдіть з Google-акаунтом.
2. **Get API key → Create API key**, скопіюйте ключ.
3. У програмі: **Пісні → ⚙ → Ключ Gemini**, вставте, натисніть **Зберегти** і **Перевірити ключ**.

Пошук в інтернеті використовує модель `gemini-2.5-flash-lite` (безкоштовний пошук Google до 500 запитів на день).
Фото й посилання розбирає `gemini-3.6-flash`. Моделі можна змінити в налаштуваннях.
У рядок пошуку можна вставити й посилання на сторінку з акордами: програма прочитає саме її.

## Пошук без ключа

Якщо ключа Gemini немає, кнопка **🔍 В інтернеті** відкриває пошук «назва акорди» у браузері
(Brave Search, Google або DuckDuckGo: вибір у **⚙ → Пошук у браузері**). Кнопка **🌐 У браузері** робить це завжди.

1. Знайдіть пісню, виділіть і скопіюйте текст з акордами.
2. Поверніться в програму й натисніть **📋 Вставити з буфера**: відкриється редактор з розібраною піснею.

Швидше: виділіть текст у браузері → **Поділитися → For Worship** (працює у встановленій програмі на Android).
Фото без ключа Gemini не розпізнаються.

## Резервна копія

**Пісні → ⚙ → Зберегти копію бази** зберігає всі пісні й служіння в один файл.
**Відновити з копії** повертає їх (наприклад, на новому планшеті).

## Розробка

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # автоматичні тести
npm run build   # збірка в dist/
```

Іконки генеруються скриптом `python scripts/make-icons.py public/icons`.
Публікація: кожен push у гілку `main` збирає й викладає програму на GitHub Pages
(Settings → Pages → Source: **GitHub Actions**).
